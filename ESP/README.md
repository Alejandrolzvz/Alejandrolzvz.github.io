Analista de datos orientado a convertir información operativa en procesos confiables, métricas claras y herramientas útiles para la toma de decisiones. Este repositorio reúne proyectos de análisis comercial, ingeniería de datos, calidad de datos y digitalización de operaciones.

## Proyectos

| Proyecto | Qué demuestra | Acceso |
| --- | --- | --- |
| **[Dashboard de ventas y rutas](../sales-pipeline-dashboard/ESP/)** | KPIs comerciales, segmentación, análisis temporal, conversión y visualización interactiva. | [Abrir demo](https://alejandrolzvz.github.io/sales-pipeline-dashboard/DEMO_Dashboard_Ventas.html) |
| **[ETL de ventas y clientes](../ETL/ESP/)** | Transformaciones con Polars, validaciones y carga en PostgreSQL. | [Ver proyecto](../ETL/ESP/) |
| **[Monitoreo de producción](../monitoreo-de-produccion/ESP/)** | Captura estructurada, extracción desde PDF y control de calidad. | [Ver proyecto](../monitoreo-de-produccion/ESP/) |
| **[Gestión y etiquetado de equipos](../equipos-y-etiquetas/ESP/)** | Estandarización de inventario, trazabilidad y etiquetas QR. | [Abrir demo](https://alejandrolzvz.github.io/equipos-y-etiquetas/demo-etiquetas/index.html) |

## Competencias demostradas

- **Análisis:** definición de KPIs, segmentación, tendencias, conversión y análisis por tiempo, ruta y unidad de negocio.
- **Datos:** limpieza, validación, deduplicación, upsert, modelado de tablas y datos sintéticos o anonimizados.
- **Herramientas:** Python, Pandas, Polars, SQL, PostgreSQL, SQLAlchemy, FastAPI, Flask, Chart.js y Docker.
- **Entrega:** dashboards explorables, APIs, pipelines reproducibles y documentación orientada a uso.

Cada proyecto incluye el problema que resuelve, el flujo de datos, las decisiones técnicas, instrucciones de ejecución y sus limitaciones.
