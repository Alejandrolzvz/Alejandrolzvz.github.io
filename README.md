## Demonstrated skills

- **Analytics:** KPI definition, segmentation, trends, conversion, and analysis by time, route, and business unit.
- **Data:** cleaning, validation, deduplication, upserts, table modeling, and synthetic or anonymized data handling.
- **Tools:** Python, Pandas, Polars, SQL, PostgreSQL, SQLAlchemy, FastAPI, Flask, Chart.js, and Docker.
- **Delivery:** exploratory dashboards, APIs, reproducible pipelines, and user-focused documentation.

## How to read this portfolio

Each project describes the problem it solves, data flow, technical decisions, setup instructions, and limitations. Public demos are static snapshots with sample data; running the backends requires the dependencies and databases described in each README.

## Contact

To review the code, start with the project that interests you and open its README. The repository is designed to show both the visual result and the technical reasoning behind it.
